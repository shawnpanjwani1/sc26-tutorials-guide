# SC'26 Tutorials — learning guide

A guided, searchable overview of all 31 tutorials from SC'26 (Supercomputing 2026, Chicago, Nov 15–16, 2026):
summaries, presenters, schedules, what you'll learn, step-by-step checklists, self-check questions and public links
(repositories, demo sites, documentation), plus 5 short basics modules.

**Open the guide:** https://shawnpanjwani1.github.io/sc26-tutorials-guide/

- `index.html` — the guide (single file, works offline; progress is saved in your browser).
- `llm-evaluation-study-guide.html` — companion study guide for "Rigorous Evaluation of LLM Components in HPC Research".

Summaries, checklists and questions are study notes written by an SC'26 attendee, not the presenters' material.
Tutorial slides belong to their presenters and are distributed to registered SC'26 attendees, so they are not included here.
Official tutorial pages: https://sc26.conference-program.com/
